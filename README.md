# AXLOS React App

## Run locally

Install Node.js 18 or newer, then run these commands in this folder:

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## Firebase sign-in

Create a Firebase web app, enable Email/Password under Authentication, then replace the placeholder values in `src/App.jsx` with the web app configuration. Add the deployed site's domain to Firebase's authorized domains.
